# K-Bond Adaptive Collector Dashboard

K-Bond 메신저의 채권 대화를 Windows 로컬 환경에서 수집하고, SQLite에 누적 저장한 뒤 검색 가능한 대시보드로 보여주는 프로그램입니다.

기존 CSV 기반 수집기의 보존용 대안으로 별도 개발되었습니다. `[채권] 블커본드`와 `[채권] 막무가내`를 한 실행 프로세스에서 관리하며, 한 방이 닫히거나 오류가 나도 다른 방의 수집을 계속합니다.

## 핵심 기능

- 네이티브 Windows 텍스트 버퍼 기반 수집
- 두 채팅방의 독립적인 연결·재시도 상태
- 한 방의 오류가 다른 방으로 전파되지 않는 격리 구조
- 메시지 변화량에 따른 적응형 수집 주기
- SQLite WAL 저장과 중복 방지용 이벤트 키
- SQLite FTS5 trigram 부분 문자열 검색
- 기존 `kbond_messages_*.csv` 자동 가져오기
- 조회 시점 고정 검색 결과와 페이지 이동
- 기관명, 종목명, 송신자, 매수·매도, 방, 날짜 검색
- 로컬 브라우저 대시보드
- 더블클릭 실행 파일
- 외부 AI·외부 서버 전송 없는 로컬 중심 처리

## 빠른 시작

1. K-Bond 메신저에 로그인합니다.
2. 수집하려는 채팅방의 대화 창을 엽니다.
3. `K-Bond_V3_실행.cmd`를 더블클릭합니다.
4. 브라우저에서 `http://127.0.0.1:5001`을 확인합니다.

첫 실행 시 `bootstrap.ps1`이 Python 3.10 이상과 Flask 환경을 확인하고, 필요하면 `kbond_v3/.venv`에 준비합니다. 기존 CSV는 프로젝트 상위 폴더에서 읽어 `data/kbond.sqlite3`로 한 번만 가져옵니다.

같은 실행 파일을 다시 눌러도 같은 V3 서버가 중복으로 뜨지 않으며, 이미 실행 중인 화면을 엽니다. 종료할 때는 수집기 콘솔에서 `Ctrl+C`를 누릅니다.

## 검색 예시

검색창에 자연스럽게 입력할 수 있습니다.

- `하나은행 채권 보여줘`
- `하나은행 매수`
- `오늘 막무가내 매도`
- `신한은행`

상세 조건에서는 검색 범위, 채팅방, 매수·매도 구분, 수집 시작일과 종료일을 지정할 수 있습니다. 결과는 조회 시점의 SQLite 행 범위로 고정되므로 페이지를 넘기는 동안 새 메시지가 결과 순서를 흔들지 않습니다.

## 기술 스택

| 영역 | 기술 |
|---|---|
| 언어 | Python 3.10+ |
| Windows 텍스트 접근 | Win32 `SendMessageTimeoutW`, `WM_GETTEXT` |
| 창 탐색 | Win32 `EnumWindows`, `EnumChildWindows` |
| 저장소 | SQLite 3, WAL, 인덱스 |
| 검색 | SQLite FTS5 trigram + 짧은 단어 보완 검색 |
| 웹 서버 | Flask, Werkzeug threaded server |
| 화면 | HTML, CSS, Vanilla JavaScript |
| 실행 준비 | PowerShell bootstrap, Windows CMD launcher |
| 테스트 | Python `unittest` |

## 적응형 수집

활동 중에는 약 0.5초 간격으로 확인합니다. 같은 텍스트가 반복되면 1초, 2초, 5초로 간격을 늘립니다. 닫힌 방이나 대화 영역을 찾지 못한 방은 약 10초마다 다시 연결합니다.

메시지 버퍼가 이전 텍스트로 시작하면 새로 붙은 끝부분을 우선 분석합니다. 버퍼가 교체되거나 중간이 수정된 경우에는 전체 버퍼를 다시 분석합니다. DB 저장이 실패하면 이전 버퍼를 완료 처리하지 않아 다음 시도에서 재시도합니다.

## 안전한 저장과 검색

각 행에는 방·메시지 시각·송신자·원문을 이용한 SHA-256 이벤트 키가 있습니다. 같은 이벤트 키는 `INSERT OR IGNORE`로 한 번만 저장됩니다. SQLite는 WAL과 `synchronous=NORMAL`을 사용해 읽기와 쓰기의 충돌을 줄입니다.

검색은 SQL 파라미터 바인딩을 사용합니다. 3글자 이상 검색어는 FTS5 trigram 색인을 우선 사용하고, 1~2글자 검색어는 해당 검색 범위의 문자열 조건을 함께 적용합니다.

## 검증

현재 자동 테스트는 12개이며 다음을 포함합니다.

- 한 방만 연결되거나 두 방 모두 미연결인 상태
- 첫 번째 방에서 오류가 난 상태에서 두 번째 방 계속 수집
- 채팅방 종료 후 재연결
- 프로그램 재시작 중복 방지
- DB 저장 실패 재시도
- 무변화 상태 호출 감소
- 새 메시지 끝부분 부분 분석
- CSV 가져오기 재실행 중복 방지와 원본 보존
- 한국어 조건·방·구분·날짜 검색
- 검색 결과 페이지 고정
- 자정·여러 줄 메시지 처리
- API 입력 검증과 로컬 정적 파일 응답

실행 명령:

```powershell
python -m unittest -v test_v3
python verify_metrics.py
```

## 한계

- 메신저가 노출하는 텍스트만 읽습니다.
- 메신저가 제공하지 않는 과거 대화를 복원하지 않습니다.
- 기존 CSV에는 실제 메시지 전송 시각이 없어 CSV와 현재 대화창의 과거 기록을 완전히 같은 이벤트로 판별하지 않습니다. 출처를 구분해 보존합니다.
- 금리 범위, 수익률 계산, 기관명 동의어, 자유로운 자연어 추론은 아직 지원하지 않습니다.
- 종목·만기 추출은 규칙 기반이므로 원문을 함께 확인해야 합니다.
- 기존 버전과 V3를 동시에 실행하면 두 수집기가 모두 동작합니다.

자세한 동작 규칙과 운영 주의사항은 [개발명세서.md](개발명세서.md)와 [사용안내.md](사용안내.md)를 참고하세요.
